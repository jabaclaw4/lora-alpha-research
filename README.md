# Исследование влияния LoRA alpha при фиксированном rank

## О проекте
Экспериментальное исследование влияния масштабирующего коэффициента `alpha` в LoRA при фиксированном значении `rank=8`. 
Цель: выявить оптимальное значение alpha, а также зафиксировать точки дестабилизации (взрыв градиентов, NaN) при экстремальных значениях.

## Состав команды и роли
*   **Участник 1 (Team Lead):** Инфраструктура, `run_lora.py`, профилирование (VRAM, время, grad_norm), запуск alpha=4, 8.
*   **Участник 2 (Data & Metrics):** Подготовка данных (`data_utils.py`), сборка метрик (`collect_metrics.py`), запуск alpha=16.
*   **Участник 3 (Experimenter):** Запуск alpha=32, 64. Тестирование стабильности.
*   **Участник 4 (Визуализация):** Построение графиков (Learning Curves), оформление презентации.

## Структура
*   `configs/` — базовые гиперпараметры (`_base.yaml`).
*   `src/` — скрипты запуска (`run_lora.py`), данных (`data_utils.py`) и сборки (`collect_metrics.py`).
*   `results/` — итоговые метрики (`metrics.csv`) и логи прогонов (`logs_alpha_*.csv`).

```bash
# Пример запуска для конкретного alpha

# Сборка всех логов в итоговую таблицу
python src/collect_metrics.py
